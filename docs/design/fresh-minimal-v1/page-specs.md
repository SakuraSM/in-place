# 页面设计说明

页面入口以 [覆盖清单](coverage.md) 和现有路由为准。稿件中的按钮只跳转视觉稿或显示“视觉示意”，不执行真实业务。筛选切换仅展示选中样式，列表内容不随之变化。

## 库存与位置

| 页面 | 视觉与层级 | 后续实现边界 |
| --- | --- | --- |
| 首页 | 紧凑概览、常用位置、最近动态；桌面双列，移动四项短统计 | 统计与最近动态应可点击；保留现有分组方式，不改变库存统计口径 |
| 库存检索 | 搜索先于筛选，物品卡保留类型、状态和路径 | 支持组合筛选、保存筛选与批量管理；返回保留检索上下文 |
| 位置树 | 桌面树与内容并排，移动先层级后内容 | 位置、收纳、物品语义不混用；可进入父级和下级 |
| 资产地图 | 控制顶部高度，让移动首屏能看到画布 | URL 筛选、地图标注权限、匹配统计与全量统计保持既有契约 |
| 物品详情 | 先图片、状态与位置，再库存操作、日期和记录 | 借出、归还、移动与编辑按原有能力接入，使用只读角色限制 |
| 收纳详情 | 收纳资料、内部物品、扫码归位与标签入口 | 位置详情继续复用现有 container 路由，通过对象类型变化展示 |
| 收纳内容 | 原生逐层浏览，路径常驻；只显示当前层内容 | Web 继续进入现有收纳详情，不新增 browse 路由 |
| 新增 / 编辑 | 共用表单，名称优先，补充字段分组 | Web 在现有弹窗 / 抽屉承载；原生使用现有 form 页面。稿件为表单内容展开板，不要求新增 Web 路由 |

地图底图沿用仓库截图的局部参考，不表示采用新的地图供应商。视觉稿的标记、示例摘要不用于数据口径验收。标注编辑、查看者只读和地图关闭 / 超时状态由真实接口和运行环境验证。

新建位置、收纳和物品可以共享字段组件，但保留不同的必填条件与数据类型。首页稿为默认状态，按类型 / 分类、层级 / 平铺等现有次级控件后续应放入共享集合工具栏，不应删除现有能力。

## 管理与采集

| 页面 | 视觉与层级 | 后续实现边界 |
| --- | --- | --- |
| 管理中心 | 基础管理、库存工具两组；桌面并排，移动上下 | 共享任务分组与导航数据；移动“管理”不是分类管理的别名 |
| 分类管理 | 物品 / 收纳 / 位置切换，同一分类图像比例 | 删除显示影响数量，不自动迁移历史分类 |
| 标签管理 | 标签名称、使用量与行末操作 | 删除与编辑保留影响确认；不能仅以颜色区分 |
| 操作记录 | 按日分组，动作、对象、时间和操作者 | 列表分页与筛选复用原能力 |
| 拍照录入 | 深色取景区、相册与拍照操作、识别流程说明 | 当前静态稿未启用摄像头；结果需人工确认后保存；无权限可手动录入 |
| 扫标签归位 | 取景区、手动输入和最近扫描 | 标签需要登录与家庭权限；不展示安全编码中的隐私内容 |
| 标签绑定 / 连续归位 | 已绑定对象摘要与已归位清单；单独给出未绑定标签状态 | 两个状态是互斥场景，稿件为了评审放在同一设计板，实际运行按返回数据选择其一 |

重复扫码不重复累计，单次失败不清空已经归位清单。无摄像头时明确替代入口；不能让静态取景框被误认为已启动的相机。

## 家庭协作与工具

| 页面 | 视觉与层级 | 后续实现边界 |
| --- | --- | --- |
| 家庭盘点 | 发起、继续进行中任务、最近完成 | 位置选择与盘点名称复用表单；分清未核对与数量为零 |
| 盘点详情 | 进度、扫码核对、实盘数量和完成前差异 | 完成前明确缺失和未盘数量；不能把未盘点默认成丢失 |
| 提醒中心 | 到期与借还的文字状态、日期、物品路径 | 保留全部现有保修、到期、借还与维护类型 |
| 库存报告 | 同一行概览，分类价值、补货和物品清单 | 金额依据已录入价格；导出和打印沿用当前实现；长表格需保留全部字段 |
| 重复物品 | 成对展示候选项，保留路径和数量 | 不自动合并或删除，逐条查看后由用户处理 |
| 标签打印 | 选择对象、布局设置与右侧预览；移动上下排列 | 使用真实打印二维码；本稿示例二维码不可绑定库存 |
| 家庭空间 | 当前家庭、成员角色、邀请和切换 | 所有者、编辑者和查看者按后端权限展示与执行 |
| 加入家庭 | 清楚展示邀请家庭与角色，再确认 | 已加入、无效、过期和无权限分别反馈 |

## 账户与补充页面

| 页面 | 视觉与层级 | 后续实现边界 |
| --- | --- | --- |
| 我的 | 个人信息、当前家庭与设置分组 | Web 不增加原生专有资料编辑 / 关于路由，现有信息可在原页面承载 |
| 编辑资料 | 单列昵称与只读邮箱 | 原生专有页面；保留当前支持字段，不额外增加头像上传 |
| AI 配置 | 服务地址、模型、密钥状态和配置来源 | 密钥不回显；错误保留输入；本稿不包含真实服务参数 |
| 账号安全 | 邮箱与密码修改 | 密码校验及所需字段以当前端 API 契约为准；表单不记录明文 |
| 数据管理 | JSON / CSV 导出按用途分行，原生保留导入 | Web 不增加尚未支持的导入；导入先预检、确认目标家庭和影响 |
| 关于 | 品牌、版本与开源说明 | 原生专有；版本从应用包读取，不能硬编码为视觉稿基线 |
| 登录 / 注册 | 桌面品牌区与表单并排，移动精简品牌内容 | 登录与注册互链；既有校验和错误反馈保留 |
| 原生地图桥接画布 | 复用地图画布和筛选视觉 | 内部 WebView 页面不再嵌套一套原生底部导航 |
| 部署状态 | 服务健康状况与检查入口 | 只用于平台模式，不混入家庭用户主导航 |

## 状态板与组件板

组件板集中展示字阶、颜色、按钮、输入、列表和标签。状态板包含空状态、加载、失败、只读、批量部分成功、删除确认、地图未启用和相机无权限，并补充无结果、邀请失效与地图失败提示。

这些示意是组件契约，不表示每种业务场景已经接入或通过验收。弹窗在应用中仍需使用现有焦点管理与平台返回机制。

## 实施顺序

先迁移共享 tokens 与布局，再迁移首页 / 库存 / 详情 / 表单，再覆盖工具与设置。每批都检查 Web 桌面、移动 Web 和原生端。地图、相机、盘点、打印和导入各自验证真实链路，不用设计截图替代功能验收。
