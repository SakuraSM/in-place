# 变更范围

这里记录原始视觉稿交付的范围。后续运行时改造另见[落地记录](implementation.md)。

- Goal：为现有全页面提供清新简约的双端视觉稿和统一规范，支持 Git 长期维护。
- Scope：仅 `docs/design/fresh-minimal-v1/` 新增设计文档、浏览源稿、静态资源与 PNG。
- Risk：不改变认证、接口、地图配置、摄像头、库存、备份或数据库行为。后续实现不能把视觉稿视为这些链路已验证。
- No-touch：保留预先存在的未跟踪 `.doc/`；不改运行中的 apps / packages、环境文件、已有图片或用户记忆文件。
- Validation：静态源码语法与引用检查；Web 1440 × 1024、移动 390 × 844 逐页渲染；检查图片、横向溢出、代表页面排版及预览导航。
- Knowledge update：本目录新增设计系统、页面说明、路由覆盖和可重现说明，不重写现有产品功能基线。
- Persistence：使用本地 `docs/fresh-minimal-design` 分支，提交本目录。未推送远端、未发布或部署。
