# UI 落地记录

目标：按本目录视觉稿改造 Web 与 Expo 全页面，先共享组件和布局，保持现有功能不变，完成双端验证。

## Impact map

- Scope：`packages/ui` 的共享 tokens 与平台适配；Web / Mobile 页面布局、展示组件和样式。
- No-touch：既有未跟踪 `.doc/`、服务端业务、数据库结构、生产环境、已有设计稿。
- Invariants：路由与导航入口、权限判断、表单字段与校验、筛选、批量部分成功、扫码归位、盘点、提醒、导入导出和地图行为不变。
- Validation：既有单测基线；修改后双端 lint / typecheck / tests、Web 构建、原生构建与运行；真实应用的桌面 / 移动 Web 和 Android 模拟器截图及交互检查。
- Knowledge：在本文件持续记录各页面覆盖、验证结果与未验收项。

## 运行检查中修正的问题

- 首页常用位置原来仍采用普通四列网格，三张位置卡右侧留空。已在首页模板中收为三列，普通库存集合继续使用四列。
- 原生平铺检索改用共享卡片内容，外层点击、长按与选择函数保持不变；层级检索继续使用列表。
- 无照片的移动详情缺少视觉稿中的插画，已补齐分类资源回退，真实照片继续优先。
- 原生欢迎区的新增沿用原有 sheet，浮动按钮在欢迎区离开视口后显示，消除首屏遮挡。
- 原生安全页退出后未离开确认框的问题在原基线中同样存在。仅补充成功后关闭确认框并替换为登录路由，已增加回归测试；没有改认证接口与凭据存储。
- 原生资料页已经实际弹出软键盘，保存按钮保持在键盘上方；双端新增物品均已通过真实 API 写入隔离数据库。
- 移动 Web 把搜索移入共享顶栏，并将分组选择并入分组标题行，保留全部原操作；三处位置名称在首屏可见，滚动后悬浮入口继续打开原表单。
- 地图桌面详情栏调整为 300 px，画布由共享尺寸定义为移动 330 / 桌面 390；筛选轨道可缩，1280 宽度不再受固定最小宽度挤压。

## 原生库存页补查

原生库存页补查修复了混合长短标题与缺省分类的错位、百分比列宽的边距偏差、失效照片空白、滚动内容进入状态栏，以及 320dp / 1.3 字号下批量入口被挤出。图片回退由平铺和层级共用；页面壳的顶部安全区固定在滚动容器外。Mobile 21 个套件、76 项测试及 lint / typecheck 通过，Android 四组屏宽 / 字号检查、详情与批量选择、共享表单键盘复查通过。[补查证据](implementation-evidence/inventory-correction/README.md)单独保留。
