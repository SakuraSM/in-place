## 已执行

1. 比对 Web 当前 27 个非重定向路由与原生端 29 个页面文件，页面清单未缺失。布局、重定向与平台模式的处理见覆盖清单。
2. 使用 Ego Lite 浏览器逐页渲染 32 个 Web 稿和 34 个移动稿。每页检查图片完整、页面标题及 document 横向宽度。结果见 `validation.json`。
3. 使用浏览器导出完整 PNG，另导出移动首页、库存首屏和总览图。页面文字与布局可由源文件重现。
4. 人工查看首页、库存、地图、表单、盘点和组件板的代表性截图，修正首屏过长、底图裁切、按钮图标对比与统计示例不一致的问题。
5. 验证总览页面模块筛选、搜索及页面链接。库存模块 8 项，搜索“物品详情”返回 1 项，再进入对应 Web 稿成功；总览 35 项无缺图。
6. 校验全部 JS / MJS 语法、主色文本对比度与 PNG 存在性。基础文本组合对比度为 4.76:1–11.35:1。
7. 执行 deterministic-frontend 基础静态门禁。此目录没有 TS / Vue / Python 文件，因此这些语言的专项门禁不适用；这不是业务应用通过类型检查的证据。
